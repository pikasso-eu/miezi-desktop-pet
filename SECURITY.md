# Security Policy

Miezi ist eine reine Desktop-Anwendung: kein Netzwerk, keine Konten, keine
Telemetrie. Ein Sicherheitsproblem ist daher selten – aber nicht unmöglich
(z. B. Pfadbehandlung in den Einstellungsdateien).

## Melden

Bitte **kein öffentliches Issue** für Sicherheitslücken öffnen. Nutze
stattdessen ein **vertrauliches GitHub-Issue**
(*New issue → Report a security vulnerability*) oder wende dich an den
Maintainer.

## Was du erwarten kannst

- Rückmeldung nach Möglichkeit, aber ohne zugesagte Frist – das Projekt ist
  Ehrenamt.
- Keine Bug-Bounty.
