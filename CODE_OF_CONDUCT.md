# Code of Conduct

## Kurzfassung

Behandle andere so, wie du selbst behandelt werden möchtest: freundlich,
direkt und auf Augenhöhe. Kritik richtet sich an Code, Grafiken und Ideen –
niemals an Personen.

## Erwartet

- Sachlich bleiben: Technisches begründen („wackelt bei Zoom 125 %“ statt
  „schlechter Code“).
- Geduld mit Fragen von Einsteigern; alle haben mal mit einer Pixelkatze
  angefangen.
- Die Spielregeln dieses Projekts akzeptieren: Beiträge entstehen auf
  Freiwilligenbasis, es gibt keine Antwort- und keine Übernahmepflicht
  (siehe [CONTRIBUTING.md](CONTRIBUTING.md)).

## Nicht toleriert

- Beleidigungen, Belästigung, trollige oder bewusst provokante Beiträge.
- Pingen oder Nachsetzen, wenn eine Antwort ausbleibt.
- Mehrfaches Öffnen desselben geschlossenen Themas („Issue-Farming“).

## Folgen

Moderation erfolgt durch den Maintainer: Hinweis → Verwarnung → Ausschluss
vom Repository. Bei wiederholten oder schweren Fällen ist der Ausschluss
sofort möglich.
